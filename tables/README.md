# Generated tables and macro files

Every file in this directory is generated. **Do not edit any of them by hand** —
re-run the generator instead. Each is overwritten in place, so `git diff` is the
check on whether a rerun moved a number.

| file | generated by | contents |
|---|---|---|
| `paper_values_benchmark.tex` | `scripts/benchmark/make_values_and_tables.py` | 202 `\newcommand` macros for the benchmark pipeline |
| `claim_ledger_benchmark.csv` | `scripts/benchmark/make_values_and_tables.py` | the same 202 values with provenance and a status field |
| `table_methods.tex` | `scripts/benchmark/make_values_and_tables.py` | attacks and audit scores as implemented |
| `table_methods_compact.tex` | `scripts/benchmark/make_values_and_tables.py` | the same table, condensed for a single column |
| `table_e1.tex` | `scripts/benchmark/make_values_and_tables.py` | the benchmark: every attack against every audit score |
| `table_stages.tex` | `scripts/benchmark/make_values_and_tables.py` | the same reversals scored under the original head and the poisoned refit |
| `paper_values_pooled.tex` | `scripts/pooled/make_values.py` | 62 `\newcommand` macros for the pooled replication |
| `claim_ledger_pooled.csv` | `scripts/pooled/make_values.py` | the same 62 values with the CSV each was asserted against |

## Where the numbers come from

In `paper_values_benchmark.tex` every macro is preceded by a comment naming the
artifact, the columns and the filter it was read from, for example:

```
% evidence/benchmark/directional_orientation/orientation_per_split.csv :: arm=canon_plus, auroc_poisoned_refit__training_dynamics, mean
\newcommand{\vStgAurocRefitTrainDyn}{0.2620}
```

`claim_ledger_benchmark.csv` carries the same provenance in tabular form.

`paper_values_pooled.tex` carries no per-line comments because each of its
values is asserted against a named CSV in `evidence/pooled/` at generation
time; `claim_ledger_pooled.csv` records which CSV for each macro.

The two generators share no value: nothing is produced by both.
